# MGS 4701 Fall 2026 - Track 2: The International BA Labor Market

## 📌 Project Overview
This project investigates the international (non-China) BA job market in 2026, focusing on job requirements, skill mixes, and salary changes, with a particular emphasis on the impact of generative AI on BA roles.

## 📂 Repository Structure
- `data/raw/`: Raw data (unmodified)
- `data/cleaned/`: Cleaned datasets
- `data/gold_set/`: Hand-coded gold set for validation
- `notebooks/`: Jupyter Notebooks for collection, cleaning, and analysis
- `docs/`: Data dictionary, collection protocol, AI use log, etc.

## 🚀 How to Reproduce
1. Clone this repository: `git clone https://github.com/aoilyan7-boop/MGS4701-Track2-Group-Global-BA-Insights.git`
2. Install dependencies: `pip install -r requirements.txt` (to be added)
3. Run `notebooks/01_data_collection.ipynb` to collect data
4. Run `notebooks/02_data_cleaning.ipynb` to clean data
5. Run `notebooks/04_analysis.ipynb` to generate analysis results
